# 运行、模型配置与数据维护

## 独立运行

本项目只需要 Node.js 20.19+（构建前端）、Go 1.26+（构建后端）及一个支持图片输入的兼容模型 API。SQLite 与文件均在自己的数据目录中，不读取或调用 yx-new-go。

在项目根目录执行：

```sh
npm ci
cp -n .env.example .env
make build
make init-admin
make start
```

访问 `http://127.0.0.1:8080`。`init-admin` 在没有指定密码时生成随机密码，请保存当次终端输出。首次运行自动提供“金相制样学习评价 v1”，四项各25分。管理员可复制并发布新规则；图谱和知识资料仍需上传真实资料并审核发布。

开发前端使用 `make dev`，页面地址 `http://127.0.0.1:3000`，API 默认监听 `127.0.0.1:8080`。后端代码修改后重新运行 `make dev`。不要同时启动两个使用同一数据目录的服务实例。

`scripts/server.sh` 加载根目录 `.env`，把相对数据与网页路径解释为相对项目根目录。`.env` 是由运维人员维护的 shell 环境文件，不接收用户上传内容；含空格或特殊字符的值需要正确引用。

## 更新已运行的版本

`make start` 执行现有 `bin/zhiwei` 并读取 `dist/`，不会编译刚修改的 Go 或前端代码。更新时先完成需要的备份，在原终端按 `Ctrl+C` 正常停止服务，再执行：

```sh
make build
make start
```

只有依赖锁文件变化时才需要先运行 `npm ci`。保持原 `.env` 和 `ZHIWEI_DATA_DIR`，不要用示例配置覆盖已配置的文件，也不要通过删除数据解决迁移问题。启动时自动应用兼容迁移；已有账号和学习记录继续使用。

## 模型配置

在 `.env` 中分别设置：

```dotenv
ZHIWEI_AI_BASE_URL=https://your-provider.example/v1
ZHIWEI_AI_MODEL=your-vision-model
ZHIWEI_AI_API_KEY=your-private-key
ZHIWEI_AI_TIMEOUT_SECONDS=300
```

地址应为兼容接口根路径，不能填聊天网页地址。模型必须同时支持图片输入和文本输出。修改后重启服务。密钥仅由后端读取，不存入浏览器，也不作为接口响应返回。不要把真实密钥提交进版本库。

未配置模型时仍可管理账号、上传文件、管理资料与查看历史；发起 AI 分析返回“模型未配置”。服务不会把示例输出冒充模型报告。配置就绪表示配置项齐全，不代表外部服务已通过连通性或专业准确性验证。

配置后先执行 `./scripts/check-model.sh --vision-only`，确认随机图片数字读取返回 `matched:true`；再执行 `./scripts/check-model.sh --image /absolute/path/to/photo.png`，提供授权真实照片，检查三类报告和保存链路。诊断使用临时数据，调用当前真实模型；完整检查最多7次模型请求。2026-10-08图片读取未通过；2026-10-09重新检查两次通过，完整验证与限制详见 `docs/VALIDATION.md`。

提交分析时，当前图片、材料背景及检索片段会发送到你配置的模型服务。选择服务商与部署方式时，应按实际教学数据的使用要求配置。

完整页面测试、角色切换与问题记录方法见根目录 `DEMO_USAGE.md`。

## 终端日志与真实任务进度

| 配置 | 默认 | 含义 |
| --- | --- | --- |
| `ZHIWEI_LOG_LEVEL` | `info` | `debug/info/warn/error` |
| `ZHIWEI_LOG_FORMAT` | `text` | 可设为 `json`，便于按任务检索日志 |
| `ZHIWEI_LOG_AI_CONTENT` | `false` | 只有设为true且级别为debug，才记录脱敏后的请求/回复正文 |

日志写到 stderr。日常 `make start` 可直接在当前终端查看。临时诊断时使用 `request_id/job_id/call_id/attempt` 对齐创建请求、持久任务和每次模型调用；不要因请求已返回202就认为模型调用已完成。

内容日志单次调用的每个方向最多32 KiB（最多头24 KiB、尾8 KiB，标记计入预算），每个正文片段最多4 KiB，每任务总预算128 KiB。图片 data URL、长Base64、配置密钥、敏感键值及think块会被屏蔽；不记录认证头或Cookie。开启内容日志仍会记录业务文字，应仅在本地排障所需期间启用。详细命令及阅读方法见 [AI 调用说明](AI_CALL_FLOW.md)。

浏览器接收已持久化的实际阶段和毫秒计时，不显示虚构百分比。token用量仅在服务商提供时保留；历史记录缺少计时字段不代表请求瞬间完成。不要用单次请求的耗时推断教学效果或模型准确性。

## 数据与备份

`ZHIWEI_DATA_DIR` 默认由启动脚本定位为根目录 `data/`。其中包含 SQLite 数据库和上传文件。数据目录、`.env` 与备份文件不进入版本库。

备份、恢复均通过独立命令完成：

```sh
./scripts/server.sh backup /absolute/path/to/new-backup.tar.gz
./scripts/server.sh restore /absolute/path/to/backup.tar.gz
```

备份目标文件必须不存在。备份先通过 SQLite `VACUUM INTO` 生成一致性数据库快照，再和上传文件一起归档为 `.tar.gz`。恢复前停止应用，并在 `.env` 中将 `ZHIWEI_DATA_DIR` 指向一个新的空目录；恢复命令不能覆盖正在使用的数据。复制一个仍在使用的 `.db` 文件不能替代一致性备份。

恢复后核对账号、样本图片、报告引用和复练记录，再切换到恢复目录。先保留原数据，不需要通过删除原目录完成恢复。

服务启动时自动执行兼容迁移，也可单独运行 `./scripts/server.sh migrate`。备份不包含模型密钥，恢复后需独立配置 `.env`。

## 教学资料管理

文本型 PDF、DOCX、TXT、Markdown 可导入为知识资料。文档经过提取、切片后先进入草稿，管理员预览并发布后才进入公共检索。扫描或加密 PDF 不会被当成成功导入，当前版本不提供 OCR。

资料引用保留当时检索的来源与内容。更新资料应形成新版本，不用新的内容改写历史报告依据。学生个人图谱属于学习记录，不等同于已审核教材；发布为共享资料需走管理流程。

启动后自动提供“金相制样学习评价 v1”，四个评分维度各25分，包含完整文字判据，标为内置教学规则。管理员可复制、编辑并发布新规则；已发布的自建规则优先，按发布时间选取最新版。历史报告保留原规则。AI 初判、学生修正、教师查看、教师复核、实验验证是不同记录，不能相互替代。

迁移4建立参考资料快照索引：已发布参考图谱和教师另行发布的匿名案例可以作为后续模型上下文，最多附加两张图。班级案例只参与相应班级检索，管理员可审核为公共参考。知识资料删除采用软删除，停止后续召回但保留已授权报告的历史引用。操作步骤见 [资料与案例使用指南](REFERENCE_WORKFLOW.md)。

## 部署与排障

- 默认仅监听本机。需要局域网访问时，显式配置监听地址及精确的来源白名单；正式部署在 HTTPS 反向代理后设置 `ZHIWEI_COOKIE_SECURE=true`。
- 前后端同源部署，无需把密钥暴露给前端。反向代理需关闭 SSE 路径的响应缓冲，并保留长连接。
- 查看失败任务的错误码、实际阶段和耗时；日志正文只通过受控开关启用，勿在排障代码中另外打印密钥、图片或未经脱敏的请求。
- 浏览器断开不终止分析。任务取消需点击取消；重新分析会创建新的任务，可能再次产生模型调用费用。
- 服务重启后，排队任务继续处理；中断的模型调用记录为失败，等待用户明确重试，不自动重复计费。
- 使用 `make test` 验证后端、前端类型、构建、lint及 `npm run test:ui`；test:ui检查静态渲染语义和SSE回放，不替代浏览器视觉或键盘焦点验收。受控模型测试只验证工程流程，不证明金相判读准确率。

## 本次升级与超时处理

迁移3会把旧示例图谱、示例知识资料和示例规则设为archived，并新增版本快照；不删除账号、学习报告、样本、文件或引用片段。历史示例不会出现在常规库列表，也不能用于新轮次或模型调用。升级前先用旧版本执行备份，再停止服务、构建并启动新版。

`context deadline exceeded` 表示调用超过等待期限，不是图片组织判断结果。旧代码存在等待响应头最多60秒的额外限制，且首次生成和一次格式修复共用总期限。现在每次模型请求独立使用 `ZHIWEI_AI_TIMEOUT_SECONDS`（默认300秒，可设1–1800），响应头与接收正文共用本次预算；最多一次格式修复，整个生成最多两个预算。网络超时不自动重试，仍需显式重新分析。提供者仍可能失败或持续缓慢，增大超时不能保证响应成功。日志按call_id/attempt记录实际耗时，失败不生成新报告，旧报告继续保留。
